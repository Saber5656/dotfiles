# COMMON completion policy validation

These checks validate the written completion contract and executable Git examples.
They do not implement or certify Saihai's runtime completion gate, deployed policy,
Bot review, merge authorization, or release.

| Layer | Command | Coverage |
|---|---|---|
| Focused contract / unit | `PYTHONDONTWRITEBYTECODE=1 python3.11 -m unittest discover -s tests -p test_completion_policy.py -v` | Required clauses, contradictory legacy wording, retained safety gates |
| Integration / procedure E2E | Same command, `IsolatedGitExample` cases | Actual Git operations in disposable repositories, with unrelated staged, unstaged, and untracked changes preserved |
| Full local suite | `PYTHONDONTWRITEBYTECODE=1 python3.11 -m unittest discover -s tests -v` | All repository policy tests; require a nonzero test count and no failures or skips |
| Static | `git diff --check` and Python `ast.parse` of `tests/*.py` | Whitespace errors and Python syntax without generated bytecode |

For this documentation scope, there is no application build, service, browser,
or device runtime to exercise. The procedure E2E is an executable contract example,
not evidence of an installed agent following the policy. The repository at the
Issue #12 base has no tracked CI workflow, test suite, or local validation profile.
GitHub's dynamic CodeQL workflow is remote-managed; its applicability and actual
result must be inventoried separately before publication/merge, never inferred
from these local tests. Existing validation and independent review gates remain.

Before each behavior commit, run the focused and full commands, record actual
start/end times, exit status, test counts, and logs against the exact intended
tree/diff, and obtain independent review. Preserve a failing pre-change run for
each new contract. After committing, verify the committed tree/diff matches the
reviewed identity, or validate the immutable commit again. Repeat the inventory
check before publishing a ready PR; changed workflow/profile/base invalidates
affected evidence.
